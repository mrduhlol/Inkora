What's inside

A serious everyday notebook.

Structured documents, organization, attachments and privacy — still offline and lightweight.

✍️

Handwriting

A huge zoomable canvas (0.1×–8×) with pen, eraser, pan, ink palette and stroke undo/redo. Ink saves as vectors, never bitmaps.

📝

Rich text

Links, tables, code blocks, headings, quotes, images and drawings. Two-tier toolbar keeps everyday tools up front.

✅

To-do notes

Typed task lists with prefilled tasks, first-task autofocus, interactive checkboxes and full autosave.

🎨

Paper colors

Orange, yellow, green, blue, white, cream, gray or black — per note, with honest contrast guarding.

🔍

Search that helps

One-tap clear and subtle match highlighting in both grid and list results.

↩️

Undo that means it

Trashing or archiving offers UNDO that actually restores — even permanent delete in Trash brings back note, tags and attachments.

🔒

App lock

Biometric lock with immediate authentication prompt. Nothing leaves the device.

💾

Backup & restore

Full backup format with note types and ink strokes. v1 and v2 backups still import.

⚡

Display size

Small / Default / Large chrome scaling from Settings, persisted and independent of note content.

Paper colors

Notes are the color. The desk stays quiet.

Eight papers to choose from, each with a folded corner and a readable ink color chosen for contrast.

Install

Three steps, no store.

Android 8.0 and up. Install via "Allow unknown apps", then open the APK. Updates arrive through future releases.

01

Download the APK

Grab the latest Inkora-v1.7.apk from the release page. It's a debug build signed for sideloading.

02

Allow unknown apps

In Settings, allow your browser or file manager to install unknown apps. One-time step.

03

Open & write

Tap the APK, install, and open Inkora. Your first note is one tap away.
